# BeerJSON 1.0.1 sample documents

These sample files were copied from the `tests/generic`, `tests/real` and `tests/converted`
folders of the [beerjson/beerjson](https://github.com/beerjson/beerjson) repository, at tag
`v1.0.1` (the same version as the schema in `examples/beerjson-1.0.1`). They are
distributed under the MIT License; see [LICENSE](LICENSE).

They are used in the test suite to check that every document can be read into the
generated types and written back to an equivalent JSON document.
