BeerJSON

BeerJSON is an open format for beer recipes and brewing data: fermentables, hops, cultures, water profiles, styles, equipment, and the mash, boil, fermentation and packaging procedures. Its schema (version 1.0.1 here, in examples/beerjson-1.0.1/) is spread over twenty files, with 92 types once translated.

The code on this page is run when the documentation is built, on sample documents from the BeerJSON repository (in test/beerjson-1.0.1-samples/).

Generating the types

The types are generated into a directory, with one file per schema file:

schema = joinpath(ROOT, "examples", "beerjson-1.0.1", "json", "beer.json")
main = generate_module(schema, joinpath(mktempdir(), "BeerJSONTypes");
                       root_name = "BeerJSON", split = true)

A BeerJSON document is an object with a single property, beerjson, which holds the version of the format and lists of records: recipes, fermentables, hop varieties, styles, water profiles...

fieldnames(BeerJSONContent)
(:version, :timing_object, :fermentables, :miscellaneous_ingredients, :hop_varieties, :cultures, :profiles, :styles, :mashes, :fermentations, :recipes, :equipments, :boil, :packaging)

The types follow the schema. For instance, a hop addition in a recipe:

@doc HopAdditionType
HopAdditionType(; kwargs...)

HopAdditionType collects the attributes of each hop ingredient for use in a recipe hop bil.

Fields

  • name::String (required)

  • producer::Union{Nothing, String}

  • product_id::Union{Nothing, String}

  • origin::Union{Nothing, String}

  • year::Union{Nothing, String}

  • form::Union{Nothing, HopVarietyFormEnum}

  • alpha_acid::PercentType (required)

  • beta_acid::Union{Nothing, PercentType}

  • timing::TimingType (required): The timing object fully describes the timing of an addition with options for basis on time, gravity, or pH at any process step.

  • amount::Union{VolumeType, MassType} (required)

  • _extra::Dict{String, Any}: additional properties, not described in the schema

Creating and writing a document

New records are created with keyword constructors, which accept plain values, and validate them. A hop addition for a dry hop:

dry_hop = HopAdditionType(
    name = "Cascade",
    alpha_acid = (unit = "%", value = 5.5),
    form = "pellet",
    amount = Dict("unit" => "g", "value" => 50),
    timing = Dict("use" => "add_to_fermentation", "duration" => Dict("unit" => "day", "value" => 4)),
)
print(tojson(dry_hop; pretty = true))
{
  "name": "Cascade",
  "form": "pellet",
  "alpha_acid": {
    "unit": "%",
    "value": 5.5
  },
  "timing": {
    "duration": {
      "unit": "day",
      "value": 4
    },
    "use": "add_to_fermentation"
  },
  "amount": {
    "unit": "g",
    "value": 50
  }
}

Structs are immutable, so to change a record, build a new one. Here we add the dry hop to the recipe and double the batch size, and then write the recipe to a new BeerJSON document:

fields(x) = Dict(n => getfield(x, n) for n in fieldnames(typeof(x)))
new_ingredients = IngredientsType(; fields(ingredients)...,
    hop_additions = [ingredients.hop_additions; dry_hop])
new_recipe = RecipeType(; fields(recipe)...,
    name = recipe.name * " (dry hopped)",
    batch_size = VolumeType(unit = recipe.batch_size.unit, value = 2 * recipe.batch_size.value),
    ingredients = new_ingredients)
new_doc = BeerJSON(beerjson = BeerJSONContent(version = 1.0, recipes = [new_recipe]))
file = writejson(joinpath(mktempdir(), "dry-hopped.json"), new_doc)
readjson(RootType, file) == new_doc
true

Invalid values are rejected, when constructing a value or reading a document:

try
    VolumeType(unit = "litre", value = 20)
catch err
    showerror(stdout, err)
end

Reading every sample

Every sample document of BeerJSON 1.0.1 can be read, and written back unchanged:

using JSON
canon(x::AbstractDict) = Dict(String(k) => canon(v) for (k, v) in x)
canon(x::AbstractVector) = Any[canon(v) for v in x]
canon(x::Real) = x isa Bool ? x : Float64(x)
canon(x) = x
files = [joinpath(dir, f) for dir in readdir(SAMPLES; join = true) if isdir(dir)
         for f in readdir(dir) if endswith(f, ".json")]
unchanged = count(files) do f
    canon(JSON.parse(tojson(readjson(RootType, f)))) == canon(JSON.parse(read(f, String)))
end
"$unchanged of $(length(files)) documents read and written back unchanged"
"43 of 43 documents read and written back unchanged"
